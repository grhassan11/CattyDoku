Format key
  VD  = converted by hand-checked script from the SVG to an Android VectorDrawable (res/drawable/<name>.xml)
  PNG = SVG uses gradients with xlink:href inheritance + gradientTransform (not representable in a
        VectorDrawable), so the matching 512x512 PNG from the same folder is shipped unchanged in
        res/drawable-nodpi/<name>.png
